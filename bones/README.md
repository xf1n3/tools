# Bone Splitter — инструмент разбиения Bedrock-модели на меши (мобильная версия)

Веб-приложение (чистый HTML/JS + Three.js, без сборки), заточенное под телефон (iPhone / Safari / GitHub Codespaces), для:
- импорта Bedrock Edition geometry `.json` (в том числе с вшитым `.obj`-мешем в виде `polyMesh`, а также обычным `cubes`-риггом);
- просмотра модели в 3D с управлением одним пальцем;
- расстановки **4 кубов-«костей»**, которые можно двигать и масштабировать прямо в 3D или через числовые поля;
- живого пересчёта: всё, что попадает внутрь куба кости, отделяется в свой меш, остальное остаётся в `main`;
- экспорта результата в `.obj` — либо архивом с отдельными файлами на каждый меш, либо одним `.obj` с группами `g`.

## Как запустить в GitHub Codespaces

ES-модули не работают через `file://`, нужен http-сервер. В Codespaces:

```bash
cd bone-splitter
python3 -m http.server 8080
```

Codespaces сам предложит открыть порт 8080 в браузере (всплывёт уведомление «Open in Browser» — жми его). Ссылка откроется прямо в мобильном Safari.

Если порт не пробросился автоматически — вкладка **Ports** внизу редактора → напротив 8080 иконка глобуса → **Open in Browser**.

## Управление на телефоне

- **Один палец, тянуть по 3D** — вращение камеры.
- **Два пальца** — зум (сведение/разведение) и панорамирование.
- **📁 вверху справа** — открыть `.json` файл.
- **Нижние вкладки**: «Кости» — список костей с полями позиции/размера, «Меши» — сколько треугольников в каждом куске, «Файл» — открыть модель / экспорт.
- **Двойной тап по кубу** в 3D — выбрать эту кость (после чего на ней появляется гизмо для перетаскивания пальцем).
- Когда кость выбрана, над нижними вкладками всплывает **мини-панель** с X/Y/Z — можно быстро подправить цифрами, не открывая шторку.
- Иконки **✥ / ⤢** сверху справа во вьюпорте переключают режим гизмо: перемещение / масштаб.
- Иконки **◼ / ▦ / #** сверху слева: сплошной режим / каркас / сетка-пол.

## Как пользоваться (последовательность)

1. Вкладка «Файл» → «Открыть .json модель» (или иконка 📁 вверху).
2. Модель появится в центре, вокруг неё — 4 цветных полупрозрачных куба (кости).
3. Двойной тап по кубу в 3D (или кнопка «выбрать» на вкладке «Кости») — выбираешь кость.
4. Тащишь её пальцем через гизмо, либо правишь числа в мини-панели снизу или во вкладке «Кости».
5. Вкладка «Меши» — сколько треугольников попало в каждый кусок, обновляется в реальном времени.
6. Кость можно выключить тумблером в её карточке — тогда её геометрия просто останется в `main`.
7. Название кости можно переименовать — оно станет именем меша в экспортированном `.obj`.
8. Вкладка «Файл» → **Экспорт**: `ZIP (несколько .obj)` — по файлу на каждый непустой меш, либо `Один .obj (группы g)` — всё в одном файле (совместимо с Blender и большинством DCC).

## Важные технические детали

- **Правило разбиения**: треугольник целиком уходит в кость, если **центр треугольника** попадает внутрь bounding-box куба этой кости (проверка идёт по мировым координатам, поэтому позиция/масштаб/центр модели не важны). Если несколько костей перекрываются — треугольник достаётся той, что выше в списке (bone_1 → bone_2 → bone_3 → bone_4).
- **Масштаб**: Bedrock geometry обычно в единицах, где 16 = 1 блок. При импорте модель домножается на `1/16`, чтобы удобно смотрелось в сцене. Это не портит пропорции и не влияет на экспорт (экспортируются те же мировые координаты, что видно в 3D).
- Формат импорта — официальный Bedrock `format_version` + `minecraft:geometry[0].bones[].polyMesh` (то, что обычно получается при конвертации `.obj` → bedrock geometry). Также поддержан классический `cubes`-риг, на случай если файл окажется обычной моделью без polyMesh.
- Экспорт — чистый Wavefront `.obj` с `v`/`vt`/`vn`/`f` (треугольники, нормали и UV сохраняются).

## Файлы

- `index.html` — разметка и стили интерфейса (мобильный, нижние шторки).
- `main.js` — сцена Three.js, тач-жесты, гизмо-кости, шторки, экспорт.
- `bedrock-parser.js` — разбор Bedrock JSON → плоская геометрия.
- `mesh-splitter.js` — разбиение геометрии по боксам костей.
- `obj-exporter.js` — сборка `.obj` текста.
- `demo-model.json` — тестовая модель-«фигурка» (тело, голова, руки, ноги) для быстрой проверки — можно сразу перетащить в приложение.
